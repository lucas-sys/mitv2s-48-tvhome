# Credits

## Upstream

The launcher in [`launcher/`](launcher/) is a port of the launcher from
**[CleanYourTV](https://github.com/Gathin23/cleanyourtv)** by **Gathin**, released under the MIT licence.
Its Java sources, tests, layouts, fonts and build files come from that project; this repository only
changes what Android 5.1 needs (see [`docs/api22-port.md`](docs/api22-port.md)) plus a wallpaper chooser
and a few device switches.

The launcher is an independent project: bugs in this fork are not upstream bugs, and changes here are
not proposed to upstream unless the maintainer asks for them.

## Fonts

`launcher/app/src/main/res/font/` and `FONT-LICENSE-OFL.txt`: the Outfit typeface, SIL Open Font
Licence. Only the framework on Android 8+ can load it; Android 5.1 falls back to the system font.

## Screenshots

The wallpaper in the screenshots is generated by upstream's `tools/scenes_wallpapers.py` (MIT).
No photos from upstream's CC BY / CC BY-SA themes are included here. The Wi-Fi network name in both
screenshots has been blurred on purpose.

Android 5.1 (API 22) compatibility work, the MiTV2S-48 device guide and the scripts:
